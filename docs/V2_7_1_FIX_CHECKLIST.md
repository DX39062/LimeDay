# LimeDay 2.7.1 冻结修复与发布清单

本文冻结 2.7.1 的修复范围。Room schema 保持 7，WebDAV/JSON 写出格式保持 v2，仍只发布 `arm64-v8a` APK。

## F1 彻底关闭预测返回预览

- [x] `MainActivity` 设置 `android:enableOnBackInvokedCallback="false"`。
- [x] 拖动期间页面不位移、不缩放、不淡出、不弹栈；取消保持路由、滚动、弹窗和草稿。
- [x] 提交后只返回一次：总结/设置回待办，二级页回上一层，待办根页退出，弹窗优先关闭。
- [x] 普通提交后的应用内转场可以保留，但不能在手势拖动期间预览。

## F2 模型服务新增入口

- [x] 页头始终显示明确尺寸的自绘加号和“新增”，触控目标不少于 48dp。
- [x] 列表底部始终显示宽按钮“新增模型服务”，已有服务时也可见。
- [x] 点击新增先显示供应商预设选择，再进入编辑器，不默认直接进入 OpenAI。
- [x] 每次新增生成新 UUID，不覆盖现有服务或默认选择。
- [x] 首次保存前提供“手动获取模型”；失败不阻止手填和保存。

## F3 待办操作图标去重

- [x] 详情使用清单/调节图形，移动日期使用日历加右箭头。
- [x] 复制、删除、优先级继续使用重叠纸张、垃圾桶和旗帜，语义图形互不重复。
- [x] 全部使用项目 Canvas/Vector 自绘，无 Material Icons、Emoji 或厂商 Logo。

## F4 紧凑完成进度

- [x] 卡片高度约 64–72dp；“完成 7 / 8”和小号“87%”同行，进度条约 5dp。
- [x] 移除大号“完成进度”标题。
- [x] 仅在当天视图且搜索为空时显示；逾期、计划中和搜索结果隐藏。

## F5 内置分组改名

- [x] 新安装固定默认分组名为“日常”，固定 ID 与 `isInbox` 兼容字段不变。
- [x] 2.7.0 升级仅将固定 ID 且名称严格为“收件箱”的内置分组改名为“日常”。
- [x] 改名幂等：重复启动不再次写入或增加 revision；不创建重复分组，不改变 Todo 引用。
- [x] “日常”不可删除，其他分组保持编辑、排序、软删除能力。

## F6 折叠搜索

- [x] 当天/逾期/计划中控件同排放置 48dp 自绘搜索和分组按钮，不常驻全宽输入框。
- [x] 点击搜索后在下方展开约 48dp 高紧凑输入框，搜索标题、备注和步骤。
- [x] 空查询并失焦时自动折叠；关闭清空并恢复进入搜索前的智能视图。
- [x] IME 完成隐藏键盘但保留结果；查询与展开状态在旋转/状态恢复后保留。
- [x] 搜索、清空、关闭均使用项目自绘图标和 TalkBack 描述。
