# LimeDay 2.6 集中设置、可靠交互与涂鸦视觉设计

## 目标与边界

2.6 在不改变离线优先、Room schema 6 和 WebDAV v1 数据边界的前提下，解决设置入口分散、模型服务操作不可发现、删除撤销反馈不可靠、日期跳转低效和视觉语言不统一的问题。

本版本不新增服务端、不上传凭据、不引入第三方图标包，也不复制厂商 Logo。所有业务数据和同步兼容性沿用 2.5。

## 一级信息架构

底部导航固定为三个一级目的地：

1. 待办：日期、进度、待办和每日复盘入口。
2. 总结：范围选择、生成控制和折叠历史。
3. 设置：待办设置、总结设置和通用设置。

待办顶部齿轮和总结顶部模型设置按钮移除。设置页作为一级目的地不显示返回按钮；回收站、模型服务和 WebDAV 仍是带返回导航的二级页。三个一级目的地使用保存状态的单顶导航，避免切换后丢失列表位置或正在填写的总结指令。

## 设置页结构

### 待办设置

- 每日待办提醒。
- 每日复盘提醒。
- 回收站入口和已删除数量。

### 总结设置

- 模型服务入口，副标题显示已保存数量和当前默认项。
- 提示词偏好说明；收藏与最近使用继续随加密 LLM 设置保存在本机。

### 通用设置

- 外观模式。
- JSON 导入与导出。
- WebDAV 状态及二级入口。
- 版本、隐私和开源说明。

## 模型服务卡片与编辑器

“模型服务”是本版本统一用词。列表可以保存多个服务，也允许同一厂商保存多份配置。

卡片采用上下两层的自适应布局：

- 上层：自绘协议图标、名称、默认状态、协议/模型、端点，以及固定在右侧的自绘铅笔按钮。
- 点击卡片主体或铅笔按钮均进入编辑器。
- 下层：文字与自绘图标组成的“测试连接”“设为默认”“更多”操作；使用可换行布局，不能依赖固定宽度横排。
- 复制、排序和删除位于“更多”菜单；删除仍需确认。

首次添加与编辑使用同一个编辑器。用户填写端点和必要凭据后，可在保存前点击“手动获取模型”。应用不会因为输入 API Key 自动联网。获取成功后展示可选模型列表，失败时保留手动模型输入与保存能力。按钮附近明确说明请求将发送到当前端点。

## 总结历史折叠

每条历史记录默认折叠，折叠态显示：

- 日期范围与周期。
- 供应商和模型。
- 指令或总结正文的单行摘要。
- 自绘展开箭头。

点击整张卡片切换展开；展开后显示指令、完整正文、是否包含已有每日总结和删除操作。展开状态仅为当前界面状态，不写数据库、同步文件或本机设置。列表可同时展开多条，不提供“全部展开”，避免误触造成超长页面。

## 月历快速跳转

中间日期卡片成为明确可点击控件，点击后打开月历弹窗：

- 初始月份等于当前选择日期所在月份，而不是强制今天。
- 点击日期立即跳转并关闭。
- “今天”快捷按钮立即回到今天。
- 有有效待办的日期显示空心圆点，全部完成显示实心圆点，同时提供语义描述，不能仅靠颜色。
- 月历只读取当前可见月份的轻量状态，不改变待办数据。

## 删除与批量撤销

左滑仍只露出固定宽度的“移到回收站”动作，用户点击动作后才执行软删除。删除后在底部导航上方显示 6 秒撤销条。

6 秒窗口内的连续删除聚合为一个批次：

- 单项：`已移入回收站`。
- 多项：`已移入回收站 N 项`。
- 点击一次“撤销”恢复批次中的全部事项。
- 新删除会重新计算剩余显示时间，防止最后一项来不及撤销。
- 页面切换不会让提示被底部导航遮挡；进程退出后仍可从回收站恢复，但不继续瞬时撤销窗口。

## 图标系统

应用内不再直接渲染 Material Icons。创建统一的 `DoodleIcon`/Canvas 图标层，覆盖：

- 一级导航：待办、总结、设置。
- 导航与日期：返回、前一天、后一天、日历、今天、展开/收起。
- 待办操作：添加、完成、更多、编辑、优先级、移动、复制、回收站、恢复。
- 总结与模型：收藏、模型服务、测试、默认、刷新、复制、排序、删除、锁。
- 设置：外观、提醒、数据、WebDAV、导入、导出、信息和前往二级页。

视觉规范：2.0–2.4dp 的略不均匀深绿线条，端点圆润，路径允许轻微偏斜；激活态使用一小块柠檬黄或浅薄荷色，不用系统默认实心图标轮廓。所有图标至少具有 48dp 触控容器和明确内容描述。

## 应用图标

核心构图为“略微歪斜的手绘便签 + 粗细不均的对勾 + 右上青柠切片”，配色为深青绿、米白、薄荷绿和少量柠檬黄。前景保持在 adaptive icon 安全区内：

- `ic_launcher_foreground.xml`：彩色涂鸦前景。
- `ic_launcher_monochrome.xml`：单色轮廓版，供 Android 13 主题图标使用。
- 圆形和圆角图标共用 adaptive 资源，避免再包一层硬编码圆角底板。

## 待办页装饰

标题右侧放置小青柠切片、三条短射线和一段波浪线。装饰绘制在现有应用栏区域，不增加页面高度，不响应点击，不持续动画，并对 TalkBack 隐藏。

## 验收标准

- 底部只出现“待办、总结、设置”三个主入口，待办/总结顶部无齿轮。
- 设置一级页无返回按钮，所有原设置能力仍可到达。
- 至少保存并展示两份同厂商模型服务；每张卡片均可通过主体和铅笔进入编辑。
- 1.3 倍系统字体下模型卡片操作不裁切；首次添加保存前可手动取模，失败可继续手填。
- 总结历史首次进入全部折叠，任意卡片可独立展开和再次收起。
- 日期卡片可打开所选月份月历、点击日期跳转，并能一键回到今天。
- 连续删除三条只显示一个可见撤销条，一次撤销恢复三条；提示位于底部导航上方。
- 源码不再直接使用 `androidx.compose.material.icons` 绘制应用内可见图标。
- adaptive、round 和 monochrome 应用图标均能由资源解析；前景在圆形与圆角遮罩中不截断。
- JVM 单测、Android 测试编译、Lint、ARM64 release 构建、APK 签名/架构/完整性检查全部通过。
- 发布版本为 `2.6.0`，标签为 `v2.6.0`，公开 GitHub Release 附带 ARM64 APK 与 SHA-256。
