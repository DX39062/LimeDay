# LimeDay 2.7.0 修改项与发布清单

本文是 2.7.0 的执行清单。实现不得以“后续再做”为由缩小下列范围；若实现细节与 `SPEC.md` 或 `TODO_DATA_AND_WEBDAV_V2.md` 冲突，以更严格、能避免数据丢失的约束为准。完成勾选必须有源码、测试、构建产物或远端 Release 作为证据。

## R1 提交后返回

- [x] 取消手势保持页面、滚动、弹窗和复盘草稿。

## R2 待办详情、组织与检索

- [x] 计划日期与截止日期/时间为独立字段；日期型截止没有伪造时间。
- [x] 单项提醒支持截止时、提前 10 分钟、1 小时、1 天与自定义时间；系统不可精确调度时安全降级。
- [x] 支持每天、工作日、每周、每月与自定义间隔；完成时幂等生成下一实例。
- [x] 新增一级分组实体、内置收件箱、自绘图标/颜色、排序、重命名和软删除。
- [x] 待办页可按分组折叠；未指定或已删分组回退到收件箱。
- [x] 新增可排序步骤实体；支持增改、勾选和删除，列表显示完成数。
- [x] 搜索覆盖标题、备注和步骤。
- [x] 提供当天、逾期、计划中视图，不增加底部导航。
- [x] 编辑器和更多操作能到达所有字段，列表保留扫描效率和无障碍描述。

## R3 智能总结总开关

- [x] `AppSettings.llmEnabled` 新安装默认 false。
- [x] 从旧设置升级且已有模型服务时首次迁移为 true；没有模型服务保持 false。
- [x] 关闭后复盘隐藏生成区域但可只读显示旧每日总结。
- [x] 关闭后总结页隐藏生成控件但保留历史。
- [x] ViewModel 生成方法也执行开关校验，不能只在 UI 隐藏。
- [x] 模型服务及加密配置不因关闭而删除，设置入口保持可用。

## R4 克制儿童涂鸦 UI

- [x] 建立统一 Doodle 颜色、线宽、圆角、边框和间距 token。
- [x] 应用内可见图标无 Material Icons、Emoji 或厂商 Logo 临摹。
- [x] 一级/二级顶部栏、按钮、卡片、开关、输入、选择芯片、分段控件、进度、空状态、弹窗和 Snackbar 使用统一应用组件。
- [x] 纸白/浅薄荷背景、深墨绿线条和少量柠檬黄强调；无纸张纹理、无旋转正文、无持续装饰动画。
- [x] 分组使用项目自绘图标和低饱和颜色。
- [x] 触控目标不小于 48dp，状态不只依赖颜色，系统动画关闭时应用动画随之关闭。

## R5 系统栏与紧凑布局

- [x] 外层导航 Scaffold 不重复消费顶部 WindowInsets。
- [x] 每个页面只由自身顶部栏消费一次状态栏安全区。
- [x] 待办标题与状态栏有效内容目标间距约 10dp，不侵入刘海/挖孔。
- [x] 待办、总结、设置、复盘、模型服务、WebDAV、回收站逐页检查顶部高度。

## R6 回收站与墓碑

- [x] 永久删除移除 Todo 与 Step 正文并创建/更新最小 TodoTombstone。
